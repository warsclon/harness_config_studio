# Issue tracker: GitHub

Issues and specs for this repository live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, update, label, comment on, and close issues with `gh issue`.
- Infer the repository from `git remote -v`.
- Pull requests are not treated as a triage request surface.
- When a skill says “publish to the issue tracker”, create a GitHub issue.
- When a skill requests the relevant ticket, fetch its body, comments, and labels.
- GitHub issues and pull requests share one number space; resolve ambiguous references before acting.
