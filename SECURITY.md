# Security reporting

The maintainer selected GitHub Private Vulnerability Reporting for this project.
The intended public repository is `warsclon/harness_config_studio`.

**Setup is pending.** The public repository and its private reporting channel have
not yet been verified as available. Do not post vulnerabilities or configuration
contents in public issues. This document does not claim that a private report can
currently be submitted.

Before public release, the maintainer must enable Private Vulnerability Reporting
in the public repository, verify its private report form, and replace this setup
notice with the verified reporting link. See GitHub's
[configuration instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).

The first supported public version is pending release. Provide affected package
and Node.js versions, operating system, reproduction steps with fictitious data,
and the impact when the reporting channel becomes available. Never include real
credentials or personal Agent Configuration Artifacts.
